description: What each current Intelligence API capability does

## Web search

Use web search to find public web, news, and supported public social-surface mentions for a person, organization, or keyword. This capability is intended for adverse-media review, public-context discovery, and triage workflows where an investigator needs normalized hits with enough context to decide what to review next.

Requests can include exact social account hints in `socialAccounts` using a supported platform plus username or profile URL. The API uses those hints to retrieve available profile and recent-activity context from the existing social scrapers and returns that context as normalized social web hits alongside general web/news search results.

Results are returned as normalized web-hit items with `confidenceCategory`, matched inputs, summary text, sanitized metadata, display domain, source type, content type, publication time when available, and `resultUrl` for the full source page URL. Web/adverse-media search intentionally exposes this URL so investigators can review the underlying page.

## PII expansion

Use PII expansion to expand supplied seeds such as emails, phones, usernames, addresses, and domains into identity candidates and related sanitized social/profile signals. This capability is intended for lead enrichment, identity-resolution support, and discovering additional candidate identifiers from known inputs.

Results may include identity-candidate items and related social-profile items. Each returned item includes `confidenceCategory`, match rationale, matched inputs, normalized attributes, and sanitized metadata so consumers can rank and review candidate links.

## Social profile match

Use social profile match to discover and score candidate social profiles against supplied subject hints such as names, locations, employers, usernames, social URLs, and natural-language matching criteria. This capability is intended for profile-discovery and profile-verification workflows where corroborating hints are available.

Results include `confidenceCategory`, scoring rationale, contradictions, profile facts, matched criteria, and sanitized recent activity when available.

## Output guarantees

Responses are designed for downstream analysis, triage, and workflow integration. They are normalized API results, not raw-source evidence exports. Confidence is returned as `likely` or `uncertain` on each normalized result item.
